# Smart Payroll System

A complete desktop-based Human Resource Management (HRMS) and Payroll system built using Python and PySide6.

## Features
- **Dashboard**: High-level overview of employee count, attendance, payroll figures, and tasks.
- **Employee Master**: Manage employee records, roles, joining dates, and departments.
- **Attendance & Leave**: Track daily attendance, approve overtime, and manage leave balances.
- **Payroll Processing**: Automatically calculate gross/net salaries, PF, ESI, TDS, bonuses, and loan EMIs.
- **Reports & Export**: Generate Excel and CSV reports for attendance, salaries, bonuses, advances, and more.
- **Salary Slips**: View and generate beautiful PDF salary slips for any given month.
- **Settings & Users**: Adjust PF/ESI rates, leave policies, and manage user roles (Admin, HR, Accountant).

## Installation
1. Make sure you have **Python 3** installed on your computer.
2. Clone or download this repository.
3. Open your terminal or command prompt and navigate to the folder.
4. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Application
To launch the application, run the following command in the project folder:
```bash
python main.py
```
